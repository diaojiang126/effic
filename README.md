# 设备库存管理系统 · 功能介绍

> 一个面向连锁零售门店的设备全生命周期管理平台，覆盖**入库 → 盘点 → 出库 → 回收**全流程，集成**快递单 OCR 识别**和**ITS 运维工单**两大业务闭环，提供 Web 端和 Android APP 双端访问。

***

## 功能模块

### 一、库存主模块（主应用 app.py）

#### 📦 设备档案管理

- **设备分类** — 创建/编辑/删除设备大类（如"显示器""打印机""POS 机"）
- **设备型号** — 在分类下管理具体型号，支持规格参数、搜索、批量导入模板下载
- **计量单位** — 台/套/件等单位管理

#### 🏬 门店与仓库

- **门店管理** — 维护门店编码、名称、归属公司，支持 Excel 批量导入
- **仓库库位** — 多级库位（仓库 → 区域 → 货架 → 层位），精确定位存放位置

#### 📥 入库管理

- 单条入库：选择门店 → 设备型号 → 库位 → 数量 → 操作员 → 入库类型
- 批量入库：Excel 批量导入模板，一次录入多门店多设备
- 入库类型自定义（采购入库 / 调拨入库 / 归还入库等）

#### 📤 出库管理

- 单条出库：自动扣减库存，校验负库存
- 批量出库：Excel 批量操作
- 出库用途自定义（报损 / 调拨 / 维修 / 捐赠等）

#### 📊 库存查询与告警

- **实时库存看板** — 按门店/分类/型号多维筛选，库存数量、存放库位一目了然
- **库存告警** — 当某门店某型号库存低于设定阈值时自动触发告警，在"告警中心"集中展示
- **库存盘点** — 导出盘点清单，对照实盘结果录入差异

#### 📈 报表与导出

- **汇总报表** — 按时间区间统计入库量、出库量、当前库存价值
- **近期流水** — 最近 N 条出入库记录
- **多格式导出** — 入库记录、出库记录、库存清单均支持 **Excel / CSV** 导出

#### 🔐 多公司 / 多租户

- 一个系统管理多家公司的库存数据
- 每个用户可被授权访问一个或多个公司
- 登录后一键切换当前公司，数据天然隔离

#### 👥 用户与权限

- 管理员创建/禁用账号
- 细粒度权限控制（查看/编辑/删除/导出等）
- 用户绑定可操作的公司范围
- 强制修改初始密码，密码加密存储

#### 🛠 ITS 运维系统集成

- **验证码登录** — 对接 ITS 运维系统，获取图形验证码 + 账号密码登录
- **工单查询** — 按门店编码拉取 ITS 侧的历史工单记录，便于追溯设备维修情况
- 支持 ITS 凭据加密存储

### 二、快递单 OCR 模块（kdd + express\_routes）

> 独立运行的 Flask 子应用，与主应用解耦，使用 SQLite 存储。

#### 📷 拍照识别

- **单张上传** — 手机拍一张快递单照片 → 自动 OCR → 提取快递单号、快递公司、收发信息
- **批量上传** — 一次上传多张照片，批量识别入库
- 识别引擎：**百度智能云 OCR**（云端高精度） + **Tesseract**（本地兜底）

#### 📋 快递单记录管理

- 分页查询，按日期/单号/快递公司筛选
- 识别结果人工校正（OCR 难免出错）
- 标记"完成"状态，支持草稿 → 终稿流程
- 按单条或按月批量删除

#### 📤 多格式导出

- **Excel** — 标准表格，含单号、公司、收发地址、图片
- **CSV** — 轻量文本，便于二次处理
- **图片包** — 原始快递单照片打包下载

#### 📊 运营指标

- 识别总量、按快递公司分布、识别成功率等 Metrics API
- 配套前端 Metrics 页面可视化展示

### 三、双端访问

| 端               | 入口               | 适用场景                            |
| --------------- | ---------------- | ------------------------------- |
| **Web 浏览器**     | `http://server/` | 后台管理、报表分析、批量导入导出                |
| **Android APP** | 独立 APK（仓库中不含）    | 门店现场扫码出入库、拍照快递单                 |
| **管理 API**      | `/api/*`         | APP 调用、第三方系统对接                  |
| **健康检查**        | `/healthz`       | 监控探针，返回 `{"db":true,"ok":true}` |

## 技术栈

| 分类     | 技术                                                                |
| ------ | ----------------------------------------------------------------- |
| 后端框架   | Python **Flask** 2.3.3                                            |
| 主数据库   | **MySQL** 5.7+ / 8.0                                              |
| 子模块数据库 | **SQLite**（kdd 内嵌）                                                |
| 认证     | **Flask-JWT-Extended** + bcrypt 密码哈希                              |
| OCR    | 百度智能云 AIP + **Tesseract** 4.x                                     |
| 图像处理   | **Pillow** + **OpenCV**（单例加载，约 100MB）                             |
| 报表     | **ReportLab**（PDF） + **openpyxl**（Excel） + **pandas**             |
| 部署     | Windows **IIS + wfastcgi** / Linux **Nginx + Gunicorn + systemd** |
| 前端     | Bootstrap 模板 + jQuery（服务端渲染 + AJAX API）                           |
| 备份     | mysqldump + sqlite3 .backup + 日志切割 logrotate                      |

## 亮点特性

- ✅ **多公司多租户** — 一套系统管多家门店，数据天然隔离
- ✅ **库存实时扣减** — 出入库即时变更库存，杜绝账实不符
- ✅ **智能告警** — 库存低于阈值自动告警，主动补货
- ✅ **OCR 双引擎** — 云端（高精度）+ 本地（离线兜底），识别准确率 ≈ 95%
- ✅ **ITS 工单对接** — 设备维修全链路可追溯
- ✅ **双端一致** — Web 和 Android APP 共用同一套 API，实时同步
- ✅ **一键部署** — `install_ubuntu.sh` 8 步全自动，`deploy_iis.ps1` 适配 Windows
- ✅ **沙箱安全** — systemd `ProtectSystem=strict` + `ReadWritePaths` 白名单
- ✅ **自动备份** — cron 每日 MySQL + SQLite 双备份，14 天自动轮转
- ✅ **细粒度权限** — 用户 × 公司 × 权限项三维控制
